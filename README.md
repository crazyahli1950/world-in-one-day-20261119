A deterministic Python program (Pillow) that draws a complete newspaper front page — "THE WORLD IN ONE DAY" — summing up the world news of Thursday 19 November 2026 in a single 1024×1024 PNG: the World Court's historic ruling that Myanmar committed genocide against the Rohingya, the Trump–Xi–Putin "peace declaration" in Shenzhen, Anthropic's record $81.3 billion IPO on a day Wall Street sold off, three tankers burning at Hormuz, the Senate's 51–48 Iran war-powers vote, and GTA VI's rave reviews, plus a markets ticker. No network, no randomness: the same bytes on every run.

## Run it

```sh
pip install pillow
python3 main.py
```

Writes the entry image to /output/entry.png (or ./entry.png when /output does not exist).
